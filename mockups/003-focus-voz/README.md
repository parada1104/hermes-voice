# Variant: Focus Voz (minimal, voz primero)

## Design stance
La voz y la conversación son el centro absoluto; todo lo demás se pliega. Máxima calma, mínima densidad — el micrófono y las fases de voz son el protagonista visual. Acento cálido terracota `#d97a3f` sobre dark profundo, vibe Superhuman/Linear minimal.

## Key choices
- **Layout:** header limpio + tab bar + sidebar compacto + chat de una sola columna, aire generoso entre mensajes.
- **Typography:** Inter con más cuerpo de lectura, JetBrains Mono solo en metadata técnica.
- **Color:** `#0b0c0e` fondo, superficies `#14161a`, acento cálido `#d97a3f`/`#f0905c` — única variante cálida.
- **Interaction:** segment de modo Voz/Chat/Agentes, selector de agente, delegaciones colapsables, ciclado de fases, anillo de onda en el mic al hablar.

## Trade-offs
- **Strong at:** legibilidad premium, sensación de calma, foco total en la voz. El menos ruidoso de los tres.
- **Weak at:** menos contexto visible — hay que expandir para ver sesiones/proyectos en profundidad; no es la mejor para multitasking pesado.

## Best for
- El usuario que usa Hermes **por voz sobre todo** y quiere una experiencia serena tipo asistente premium. Es la variante para "charlar + delegar a veces", no para orquestar muchos agentes a la vez.
